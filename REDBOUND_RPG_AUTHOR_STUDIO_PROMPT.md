# REDBOUND PRODUCT PROMPT — CONSOLIDATED

Build Redbound as a beautiful RPG-style creation system for writing novels and any other kind of book on both the web and Android.

## 1. RPG book-creation workspace

Create a production-quality writing application with a strong RPG identity. Users can create multiple projects and organize them into default or custom sections for brainstorming, outlines, chapter planning, scenes, characters, relationships, worldbuilding, locations, lore, power systems, plot development, timelines, continuity, themes, research, rough drafts, final drafts, and publishing notes.

Each section behaves like its own focused workspace. Opening a section should feel like entering a separate room or window. The user can return to the main project menu at any time. Users can create additional tabs/sections to match their own workflow.

## 2. Persistent AI assistant

Myria is the fully integrated assistant. When the user opts into microphone access and the platform supports continuous recognition, she continuously listens for completed speech and can respond without requiring the user to tap the chat box first.

Her creative workflow is:

PLAN → ACT → REVIEW → REVISE → SELF-REVIEW

She should repeat review/revision only when it materially improves the result, then stop. She must use concise external plans/checklists and polished output rather than exposing hidden chain-of-thought.

For signed-in users, project notes, Myria conversation history, structured goals/tasks, and durable project context are stored in the shared cloud backend. The website and Android app use the same backend so a user can ask what they last did on the other device. Guest mode remains device-local.

## 3. Visual direction

Make the interface premium, cinematic, mobile-friendly, and RPG-like without becoming hard to use. Cherry blossoms continuously fall in the background over a moonlit pond with subtle reflected light and ripple animations. Use deep midnight blues, soft sakura pink, muted jade, warm gold, and parchment-white text. Panels should feel like elegant glass RPG menus.

The layout must adapt cleanly to phones, tablets, and desktop displays. Navigation should remain reachable on mobile and focused writing views should minimize distraction.
